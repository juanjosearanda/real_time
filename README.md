# Experimentos con el SO de tiempo real QNX 8.0

## 1. Obtener el QNX Software Development Platform 8.0 de forma gratuita para uso personal y no comercial a través de la iniciativa QNX Everywhere.

> • Crear una cuenta: Regístrate para obtener una cuenta de myQNX en el sitio web oficial de QNX.
> • Aceptar los términos: Inicia sesión y acepta los términos de la licencia para uso no comercial.
> • Activar la licencia: Espera unos minutos a que aparezca en el administrador de licencias y actívala.
> • Descargar el software: Instala el QNX Software Center para descargar el sistema operativo y las herramientas de desarrollo.

Qué incluye el programa
> • Plataforma completa: Acceso al sistema operativo QNX OS, herramientas de depuración y compiladores.
> • Uso permitido: Ideal para estudiantes, aficionados, investigadores y proyectos de código abierto que no generen ingresos.
> • Soporte y comunidad: Acceso a foros, documentación y recursos en línea.

## 2. Las arquitecturas de destino (Target) disponibles son:
> • ARM de 64 bits (AArch64): Compatible con hardware basado en las especificaciones Armv8 y Armv9. Esto incluye SoCs avanzados para automoción, robótica y placas de desarrollo populares como la Raspberry Pi 4 y Raspberry Pi 5.
> • x86 de 64 bits (x86_64): Compatible con procesadores modernos de Intel y AMD (como la línea AMD Ryzen Embedded).

- Las compilaciones x86_64 pueden emularse utilizando entornos virtuales mediante la creación de máquinas virtuales generadas para QEMU, VMware o VirtualBox.

## 3. Entornos de desarrollo compatibles (Hosts)
Instalar las herramientas de desarrollo y compilación cruzada (QNX Momentics IDE o el toolkit de VS Code), en computadoras con los siguientes sistemas operativos:
> a) Microsoft Windows 10 y Windows 11 (64 bits)
> b) Linux:	Ubuntu Desktop (20.04, 22.04 y 24.04 LTS) o Red Hat Enterprise Linux 9
